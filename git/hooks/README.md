# UXUTIL/GIT/HOOKS

Git hooks I use across my repositories.  Install a hook into a repo by
symlinking it into that repo's *.git/hooks/* — the *git-install-hook* utility
does exactly this for every executable hook found here.

## Hooks:

### pre-commit
*runs automatically on `git commit`; run it manually with `git pre-commit`, or `.git/hooks/pre-commit --all` to scan every tracked file (not just the staged ones)*
<br>Rejects the commit if any checked file contains:
* the markers *FIXME*, *NOCOMMIT*, or *XXX*
* leftover merge-conflict markers (*<<<<<<<*, *=======*, *>>>>>>>*)
* *NULL* in C++ source (allowed in *.c*, *.h*, and *.md* — use *nullptr* in C++)
* trailing whitespace (skipped for *.md*, which uses it for line breaks)
* TAB characters, except where tabs are required — *Makefile*, *.mk*, *.go*, and *go.mod*/*go.sum*/*go.work*

It also rejects tracked symlinks, warns when a file is both staged and further
modified in the working tree, and blocks commits made directly to the default
branch (*master*/*main*) unless a *.gitnorestrict* file exists in the repo root.

Files matching an entry of the *[ignore-commit-scan]* section of the repo's
*.gitrules* (see below) are not scanned.

### pre-push
*runs automatically on `git push`*
<br>Refuses a push to any branch listed in the *[restrict-push]* section of the
repo's *.gitrules* (see below), so those branches change only through PRs.
With no *.gitrules*, or no such section, every branch may be pushed to.

It also refuses to push any commit whose message carries a co-author or
attribution tag: a *Co-Authored-By:*, *Co-developed-by:*, *Assisted-by:*,
*Generated-by:* or *Claude-Session:* trailer, or a line starting *Generated
with* / *Generated by* (optionally after 🤖), matched ignoring case at the start
of a line.  These are the tags *setup/claude/hooks/no-attribution.sh* blocks;
unlike that Claude Code hook, this catches commits however they were made.
Only commits not yet on any remote-tracking branch are checked.

## .gitrules

Repo-local rules for the hooks above, kept in a *.gitrules* file in the root of
the repo's main checkout (linked worktrees use the main checkout's file).  It
holds sections in brackets, one entry per line; *#* starts a comment, and blank
lines and surrounding whitespace are ignored:
```
[restrict-push]          # pre-push: branches that may not be pushed to
main-thru

[ignore-commit-scan]     # pre-commit: paths whose files are not scanned
firedancer
```
An *[ignore-commit-scan]* entry matches whole path components anywhere in a
file's path: *firedancer* skips *patch/firedancer/a.cpp* (but *fire* does not),
and *patch/firedancer* skips everything under that directory.

*.gitrules* is meant to stay local to the checkout: keep it out of commits by
adding it to *.git/info/exclude*, or to your global ignore file
(*~/.config/git/ignore*) to cover every repo.
