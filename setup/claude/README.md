# UXUTIL/SETUP/CLAUDE

The Claude Code files installed into *~/.claude* (or *$CLAUDE_CONFIG_DIR*), and the script that installs them.

## Utilities:

### setup.sh
*claude/setup.sh \[-f\] \[-n\] \[-i|-I\] \[-h\]*
<br>Install *CLAUDE.md*, the hooks in *hooks/*, the generic skills in [*../skills/*](../skills/README.md) and any in a *skills/* directory here, and merge the sections in *settings/* into *settings.json*.  It also warns unless Claude Code's own *~/.claude.json* (*$CLAUDE_CONFIG_DIR/.claude.json* when that is set) has *leftArrowOpensAgents* false, so a stray left arrow can't open agent view.  That file is only checked, never changed, because Claude Code rewrites it while it runs; the warning says to turn off *← opens agents* in */config*, which lists it only while agent view is on (*claude --settings '{"disableAgentView":false}'* turns agent view on for one session).  [*setup-agents.sh*](../README.md#setup-agentssh) runs it; it can also be run on its own.  Needs *jq*.  *-f*, *-n*, *-i*, *-I* and a *config.ignore.txt* here work as they do for *setup-agents.sh*.

## Files:

### CLAUDE.md
*(installed as ~/.claude/CLAUDE.md)*
<br>My global instructions for Claude Code: never add an attribution line to a commit or pull request, fix every bug and review finding with strict red-green TDD, and run and report the project's gates (formatter, linter, the full affected test suite) before calling a change done.

### hooks/
*(installed into ~/.claude/hooks)*
<br>Claude Code hook scripts.  Each is installed like any other file (one that already exists and differs is kept unless *-f* is given), and nothing else in *~/.claude/hooks* is touched; the settings section that runs a hook adds it to *settings.json* next to any hooks already there.
* [*no-attribution.sh*](hooks/no-attribution.sh) -- a *PreToolUse* hook for the *Bash* tool that blocks a *git commit*, *gh pr create* or *gh pr edit* whose message carries a co-author or attribution tag, whoever it names (a *Co-Authored-By*, *Co-developed-by*, *Assisted-by*, *Generated-by* or session-link trailer, or a line starting *Generated with* or *Generated by*), whether in the command itself or in a file passed with *-F*, *--file* or *--body-file*; run by *setting_attribution.json*

### settings/
*(merged into ~/.claude/settings.json)*
<br>Claude Code's *settings.json*, kept in sections: one *setting_\<section\>.json* per section.  Any file added here whose name matches *setting_\*.json* is picked up, and other files are ignored.  The sections are combined, in name order, before anything is merged, so *-n* reports each setting once; two sections setting the same value differently stop the run with an error, even with *-f* (lists, as everywhere, are combined).
* [*setting_general.json*](settings/setting_general.json) -- *xhigh* effort (also for *claude-opus-5-5* in *modelSettings*), the *dark-daltonized* theme, auto-compact off, and the workflow usage warning skipped
* [*setting_spinner.json*](settings/setting_spinner.json) -- my spinner verbs, appended to Claude Code's own
* [*setting_attribution.json*](settings/setting_attribution.json) -- no attribution on commits or pull requests (*attribution.commit* and *attribution.pr* empty, *attribution.sessionUrl* off), and the [*no-attribution.sh*](hooks/no-attribution.sh) hook as a backstop, appended to *hooks.PreToolUse* so any hooks already there are kept (lists are only ever added to, even with *-f*)
* [*setting_agentview.json*](settings/setting_agentview.json) -- agent view off (*disableAgentView*), so a stray left arrow can't drop a session into it; this also turns off *claude agents*, *--bg*, */background* and the on-demand daemon
