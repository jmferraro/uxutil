# UXUTIL/DOC

Plain-text notes kept for reference.  None of them are commands, and nothing installs them.

## Files:

### colors.txt
<br>Hex RGB values for a short list of named colors (blue, orange, pink, purple, red, white, yellow, and a few known by a number, such as *1837*), written out twice in slightly different forms.

### new-ubuntu.txt
<br>Checklist for a new Ubuntu machine: the packages to install with *apt* and *snap* (git, compilers, *vim-gtk3*, *meld*, *tkcvs*, *rmlint*, *shellcheck*, ...), generating an SSH key and copying it to a host, optionally enabling the SSH server through *ufw*, and turning on X11 forwarding in *~/.ssh/config*.

### other-desktops.txt
<br>How to see the current desktop (*$XDG_CURRENT_DESKTOP*), and the *apt* packages that install other desktop environments: MATE, Cinnamon, GNOME, KDE Plasma, UKUI, XFCE, LXDE and LXQt.  The section on switching between them is still empty.
