# UXUTIL/DOTFILES

Configuration files meant to be linked into the home directory as the matching dot file.  No setup script installs these; link them by hand.

## Files:

### gdbinit
*(link as ~/.gdbinit)*
<br>gdb settings: save the command history (up to 10000 entries) in *~/.gdb_history*, show disassembly in Intel syntax, and enable *debuginfod* so gdb can download missing debug information.
